# FYND

충남 곳곳의 좋은 가게를 직접 만나 기록하고, 손님이 찾아볼 수 있게 소개하는 FYND 공식 웹사이트입니다.

## 로컬 실행

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다.

## 페이지 구성

- `/about.html` — FYND 소개
- `/services.html` — 하는 일
- `/process.html` — 진행 방식
- `/faq.html` — 자주 묻는 질문
- `/contact.html` — 가게 소개 문의

## 배포

`render.yaml`이 포함되어 있어 Render Static Site로 배포할 수 있습니다.

## 이미지 출처

`assets/images/`의 현장 이미지는 이 프로젝트용으로 제작하거나 FYND 서비스웹의 실제 참여 업체 자료를 재사용했습니다. 메인 이미지는 사용자가 제공한 사진의 구도와 피사체를 유지한 채 웹 화면에 맞게 명암과 색감만 조정했습니다.
FYND 로고는 기존 FYND 서비스웹의 원본 로고 파일을 활용했습니다.
